# Inherited Paper 1 Derived Inputs

This directory contains selected derived artifacts inherited from the Paper 1 distance-balanced residual-disturbance packet.

The retained files are used only as frozen inputs for Paper 3 candidate triage:

- `taucore_specificity_point_map.csv`: pointwise absolute residuals for TPG/projection, MOND-simple, and RAR-like comparators.
- `taucore_specificity_galaxy_bin_map.csv`: binned galaxy-level residual summaries.
- `baseline_score_by_galaxy.csv`: galaxy-level baseline residual-score table.
- `baseline_score_comparisons.csv`: A/C baseline comparison summary.
- `selection_observability_summary.csv`: class-level distance and observability summaries.
- `taucore_extended_formula_comparison.csv`: inherited comparison of fixed and S_tau-gated formulas.
- `external_evidence_table.csv`: frozen external evidence table from the residual-blind labeling audit.

These are derived reproducibility artifacts. Raw SPARC rotmod files are not redistributed here.
