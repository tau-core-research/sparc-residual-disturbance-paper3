The `paper3_s_tau_*` tables are inverse diagnostics. They estimate the local `S_tau(R)` needed to bridge the frozen TPG/projection baseline and measured SPARC velocities, then compare simple functional families in sample. Because the diagnostic uses the measured endpoint, it is descriptive and endpoint-conditioned. It is not a predictive field reconstruction and not independent physical evidence.

All rows are intended as reproducibility artifacts for the exploratory candidate framework. They should not be read as a model-selection result or validation claim.
