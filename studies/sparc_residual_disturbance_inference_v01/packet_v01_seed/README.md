# Inherited Paper 2 Derived Inputs

This directory contains selected derived artifacts inherited from the Paper 2 residual-shape inference packet.

The retained files provide galaxy-level residual features and observability/environment summaries:

- `residual_feature_table.csv`
- `distance_resolution_environment_join_v01.csv`
- `p09_observability_decomposition_join_v01.csv`
- `paper2_observability_covariate_appendix_v01.csv`

These files are used by Paper 3 to compare TPG/projection residual burden with MOND-simple and RAR-like residual burden, and to screen candidate Tau Core channels against distance, inclination, environment, and reconstruction-risk proxies.
